# SPR-001 - Sprint Reflection

## 1️⃣ Role Assignment

**Role:** Software Developer (Desenvolvedor de Software)

**Nome do profissional:** Software Developer.

**O que esse profissional faz?**
O Software Developer desenvolve, testa, corrige e mantém sistemas e aplicações, trabalhando em equipe para criar soluções que atendam às necessidades dos usuários.

## 5️⃣ Sprint Reflection

A Issue mais fácil foi criar a estrutura inicial do projeto.

A Issue mais difícil foi organizar as tarefas e entender alguns requisitos do sistema.
